BAIKU PHASE 8 — REAL eSewa ePay V2 (UAT)

1. Back up C:\xampp\htdocs\baiku2.
2. Copy the Phase 8 files into C:\xampp\htdocs\baiku2.
3. Do NOT import the old SQL schema again.
4. Make sure Apache + MySQL are running.
5. Log in to Baiku as your admin.
6. Open http://localhost/baiku2/esewa_setup.php once.
7. Confirm it says setup complete.
8. DELETE esewa_setup.php from C:\xampp\htdocs\baiku2.
9. Log in as the normal customer and go to checkout.
10. Select eSewa and continue. The browser will be redirected to eSewa UAT.

Official UAT ePay V2 values used by this build:
- Product/service code: EPAYTEST
- Secret key: 8gBm/:&EnhH.1/q
- ePay form: https://rc-epay.esewa.com.np/api/epay/main/v2/form
- Status check: https://rc.esewa.com.np/api/epay/transaction/status/

The UAT test credentials are published by eSewa in its developer documentation. Use the currently listed UAT test eSewa ID/password/token there rather than real wallet credentials.

IMPORTANT:
- This is UAT/testing, not live money.
- Never put a production secret key in JavaScript.
- The success response is signature-checked and then server-side status is checked with eSewa before an order is marked Paid.
- eSewa orders reserve/decrease stock while payment is pending. A failure/cancellation restores stock and the cart.
- If the browser is closed or the UAT service is unavailable after payment initiation, the order can remain Pending Payment. The admin should not manually mark it delivered until payment is verified.

After UAT testing works, production credentials/URLs should be moved into config.php only after the merchant account is approved.
