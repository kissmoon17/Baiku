BAIKU — PHASE 5
================

Phase 5 adds a protected MySQL-backed admin dashboard.

NEW FILES
----------
admin.php              Protected dashboard page
admin_api.php          Admin-only product/order/customer API
admin-setup.php        One-time first-admin creation page
js/admin.js            Dashboard logic

UPDATED FILES
-------------
admin.html              Redirects to protected admin.php
admin_guard.php         Redirects unauthorized visitors to login
login.html              Admin login now opens admin.php
css/style.css           Admin CRUD/dashboard styles

FIRST ADMIN SETUP
-----------------
1. Make sure Apache and MySQL are running in XAMPP.
2. Open:
   http://localhost/baiku2/admin-setup.php
3. Create your administrator account.
   Use a strong password of at least 8 characters.
4. You will be logged into admin.php automatically.
5. DELETE admin-setup.php from C:\xampp\htdocs\baiku2 after setup.

IMPORTANT
---------
- Do NOT import SQL again.
- Do NOT put a plaintext password into the database.
- Product "Remove" is a soft delete: it sets active=0 so old order history
  and foreign keys remain safe. Inactive products can be restored by editing.
- Every admin API action checks the PHP session and role=admin.
- Customers cannot open admin.php successfully; they are redirected to login.

ADMIN FEATURES
--------------
Overview: live product/customer/order counts, revenue, recent orders.
Products: create, edit, feature, stock, image path/URL, activate/deactivate.
Orders: view orders, line items, customer/address details, update status.
Customers: registered customer list, order count, total non-cancelled spend.

TEST CHECKLIST
--------------
A. Open admin-setup.php and create the first admin.
B. Confirm phpMyAdmin -> baiku2_db -> users shows role = admin and a password hash.
C. Open admin.php directly.
D. In Products, edit one product and refresh; the change should persist.
E. Add a temporary product and then remove it; it should become Inactive.
F. Open Customers; the Phase 4 test customer should appear.
G. Logout; open admin.php again. You should be sent to login.html.
H. Log in as the customer account; admin.php must still refuse access.
I. Log in as the admin; login should redirect to admin.php.
